# 🚀 DevDash

A real-time developer dashboard that consolidates GitHub tasks, system performance monitoring, and personal task management into one clean interface.

![Dashboard Screenshot](https://via.placeholder.com/800x400?text=DevDash+Dashboard)

## Problem Solved

Developers waste 15-20 minutes daily switching between GitHub, task managers, and system monitors. **DevDash solves this** by bringing everything to a single dashboard.

## Features

✅ **GitHub Integration** - View all issues and PRs assigned to you  
✅ **System Monitoring** - Real-time CPU, memory, and uptime stats  
✅ **Task Manager** - Persistent todo list with localStorage  
✅ **Dark/Light Mode** - Toggle between themes  
✅ **Auto-Refresh** - Data updates every 60 seconds  
✅ **Responsive Design** - Works on desktop and tablet

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React 19, Vite, Tailwind CSS |
| Backend | Node.js, Express |
| State Management | TanStack Query |
| API Integration | GitHub REST API |
| Caching | Node-cache |
| Persistence | LocalStorage |
